# A股大行情 —— 应用档案

三键 A 股自选行情工具（`astock-quote`）的纯文本应用档案：数据链路、规则、
AI/网络结构与测试覆盖。封面图与商店元数据不进仓库。

## 数据链路

```
东财 push2.eastmoney.com  (HTTP, UTF-8 JSON)
  └─ sq_net: raw-socket GET（hot-daily 真机教训：esp_http_client 在
     C3+lwip 上组件内部失败，socket 直连验证可用）
      └─ sq_quote: cJSON 解析 → 快照（价格/涨跌均 ×100 定点，停牌"-"记无效）
          └─ NVS 缓存（断网回放） + 回调（LVGL 锁内投递列表页）
```

一次请求拉全部自选（secids 逗号列表，沪 `1.` 深 `0.` 前缀）。盘中（北京
时间 9:15–15:05，周末除外）按设置间隔自动刷新；服务器 f124 时间戳随快照
落缓存，断网时列表显示最后报价并标注「显示缓存」。

## 规则要点

- 自选上限 8 只；同代码在指数域与个股域可并存（000001 既是上证指数也是
  平安银行，东财 secid 分别为 1.000001 / 0.000001）。
- 个股代码首位推断市场：6/9/5 沪、0/2/3 深；北交所（4/8）一期明确拒绝。
- 停牌：数值字段为 `"-"`，解析为无效 —— 界面显示「停牌/无数据」，绝不
  显示 0.00 冒充行情。
- 无交易时段日历（节假日）：时段判定只到「周末 + 每日窗口」粒度，节假日
  里刷新拿到的是上一交易日数据，由服务器时间戳如实标注。

## 配网

esp-wifi-connect 组件（hot-daily / english-podcast 同款，本硬件验证过）：
标题页「Wi-Fi 配网」→ 设备开热点 **AStock** → 手机连热点访问 192.168.4.1
输入家 Wi-Fi（2.4G）→ 组件存 NVS、自动重连。配网页支持清除凭据重新配网。
hot-daily 真机教训原样沿用：联网成功后显式设置 DNS（DHCP DNS 会让首次
HTTP 超时）。

## 测试覆盖

- `test_sq_symbol`：代码校验与市场推断（含北交所拒绝）。
- `test_sq_quote`：真实报文形状、停牌占位、坏 JSON、快照序列化回读
  （cJSON 用 tests/cjson 单文件同源版编译）。
- `test_sq_market`：交易时段边界（集合竞价、午休、收盘后、周末；
  timegm 不可移植 → 测试用 Hinnant civil-days 算法替代）。
- `test_sq_watch`：预设、增删去重（同码两域并存）、上限 8、序列化回读。
- `test_sq_volume` / `test_sq_wrap`：家族通用。

## 交付注记

- 字库三档（16/24/32px，Noto Sans CJK SC，SIL OFL 1.1），UI 子集
  （327 码点）。股票名以「代码.市场 + 预设英文简称」显示（MOUTAI、SSE…），
  刻意不收动态中文字形 —— 省下约 1.9MB Flash。
- 无 TLS：行情走 HTTP 明文（公开数据无凭据），省 ~45KB 堆与证书负担。
- 任务与栈：输入 24KB、网络 16KB；BLE 不初始化（配网走热点）。
- 已知限制：无节假日日历；停牌股显示「无数据」；东财接口未加密。
